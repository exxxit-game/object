# Доска

Мера прогресса одна: ты увидел и сказал «да». Каждый диалог начинается со строки в «Показах» (что ты сегодня увидишь) и кончается показом тебе — в очках или картинкой. Два диалога подряд без твоего «да» — только видимая работа, побочная стоит. Это единственное место, где записана очередь работы; она идёт по твоим решениям. Твои решения: docs/owner-decisions.md. Большой план — архив и стратегия: https://claude.ai/code/artifact/71113d16-57ad-42ce-9905-87ff87dfdbd7

## Сейчас
- Копия папки со статьями (её нет нигде, кроме ноутбука), затем первая вещь коридора: картины на торцах.

## Путь — ступени и проверка каждой
1. Коридор готов — ты сказал «да» каждой вещи списка ниже.
2. Первая комната — 2–3 пробные по 5 минут, ты выбрал одну; затем прошёл её целиком и сказал «да». Начинается с карточки опыта (docs/catalog.md).
3. Тестеры — 5–10 из твоего сообщества ставят приложение через закрытый тестовый канал Meta; их записи пришли.
4. Ворота 0 — 7 из 10 дошли до конца, средняя оценка от 7 из 10.
5. Выход в магазин Meta.
6. Рост — бизнес-петля крутится.

## В каждом диалоге — одна видимая вещь и кусок внутренней работы
Коридор до конца (вещь, не показанная за два диалога, режется или упрощается):
1. Картины на торцах коридора
2. Указатель этажей у лестницы
3. Свет и мрачность коридора (сначала найти причину)
4. Огнетушитель: верх по фото настоящего
5. Отрывные полоски на объявлении
6. Подписанный бланк висит на доске заполненным
7. Тексты коридора: приветствие — серьёзное; мелкие сухие детали на бумаге — можно (юмор голосом — только в комнатах)

Внутренняя работа, по очереди, каждая — до своей ступени:
1. Копия папки со статьями — её нет нигде, кроме ноутбука (до всего)
2. GitHub полностью: main только через проверку, выпуски с номером (до ступени 3)
3. Комната встаёт за дверью коридора, а не коридор внутри комнаты; бюджет кадра Quest 2 (до ступени 2)
4. Данные перед тестерами: шлёт только настоящая сборка, комната в списке сервера, время без секунд, страница о данных (до ступени 3)
5. Установка: манифест, значок, ключ подписи, тестовый канал Meta (до ступени 3)
Потом: голос в очках — мои надписи вслух, твои ответы через микрофон очков (твоё желание; голос уходит в службу распознавания — решишь ты).

## Ждёт тебя (не больше трёх)
1. Сказать, как прошла проба контроллеров и рук: «да» или что не так.
2. В конце шага, одним действием: выключить в настройках claude.ai коннекторы Notion, Jam, Adobe, Figma, GitHub.
3. К ступени 3: аккаунт разработчика Meta — создать можешь только ты; напомню, когда дойдём.
