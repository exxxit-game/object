# Claude Code practice (from the claude-code-guide agent, docs fetched 10.10.2026)
1 CLAUDE.md: facts for every session; "Would removing this cause Claude to make mistakes? If not, cut it."; target under 200 lines; area rules to skills or .claude/rules with paths; imports do not cut context cost; it is "context, not enforced configuration" - must-always steps go to hooks. https://code.claude.com/docs/en/memory , /best-practices
2 Skills: only the description loads each turn, the body on use; SKILL.md under 500 lines with linked reference files; description cut at 1,536 chars. Libraries: just-in-time retrieval, "lightweight identifiers", glob/grep; a one-line-per-paper index plus a skill that greps it and opens only the cited paper (inference). https://code.claude.com/docs/en/skills ; anthropic.com/engineering/effective-context-engineering-for-ai-agents
3 Subagents: for verbose output, enforced tool limits, summary returns; fresh context, get CLAUDE.md not auto memory; tools allowlist, disallowedTools; maxTurns gives resumable partial output; cost: own tokens; returns often 1-2k tokens. https://code.claude.com/docs/en/sub-agents
4 Hooks: deterministic must-happen steps; Stop hook overridden after eight consecutive blocks; SessionStart must be fast; 10,000-char cap on added context, beyond it only a 2,000-char preview and Claude is not told to read the file. https://code.claude.com/docs/en/hooks-guide
5 Memory/context: MEMORY.md first 200 lines or 25KB per session, topic files on demand; compaction clears old tool outputs then summarizes, early detailed instructions may be lost; survives: CLAUDE.md, unscoped rules, auto memory, recent files, invoked skill bodies; conversation-only instructions are lost; /compact <focus>, Compact Instructions section, SessionStart compact matcher re-injects state; long-running harness: progress log + JSON feature list + git + read-first step. https://code.claude.com/docs/en/context-window ; anthropic.com/engineering/effective-harnesses-for-long-running-agents
6 MCP: at start tool names and server instructions load, schemas deferred (tool search); instructions cut at 2,048 chars; disable unused servers in /mcp; CLI tools are the most context-efficient; external-content servers risk prompt injection. https://code.claude.com/docs/en/mcp
7 Worktrees/handoff: named worktrees, resume by name, transcripts kept 30 days; for a large task write a spec then execute in a fresh session; checkpoints are not git. https://code.claude.com/docs/en/worktrees
Synthesis (inference): short CLAUDE.md with pointers; skills for procedures and an on-demand paper index; hooks for must-always checks with short output; subagents for bulk reading returning summaries; progress file + git as handoff; /compact and /clear between tasks; unused MCP servers off.
