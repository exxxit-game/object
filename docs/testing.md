# Testing

| Command | What | Where to run |
|---|---|---|
| `npm run morning` | The morning check (`tools/morning.mjs`): nothing uncommitted or unpushed, what stays on this laptop, nothing private in unpushed commits, the push guard on and main protected on GitHub, the last GitHub run, `npm test`, every tool parses, the headset's link, battery and sleep, the code against the last audit | Locally, first thing each day |
| `node tools/secrets.mjs [range]` | No key, token or own email in the commits about to be pushed; git runs it before every push (`tools/hooks/pre-push`, set once per clone: `git config core.hooksPath tools/hooks`), and `tools/publish-preview.mjs` on the copy it pushes | Locally, by git |
| `tools/hooks/pre-commit`, `tools/hooks/pre-push` | No commit while `npm test` fails; no push to main (the live site) without `OBJECT_LIVE=owner-said-yes`, typed only after the owner's word; `tests/secrets.test.mjs` runs both hooks and the secret check on real commits | Locally, by git |
| `npm test` | Node only, about a second: structure rules (`tests/structure.test.mjs`, docs name no constant the code lacks), the room protocol pinned to the paper, schedule, report, reveal pages, every recording and sound present (and every corridor sound has a measured gain), file names safe from ad blockers, VR recenter math, tile and block layout (`tiles`, `masonry`), the building standards (`standards`), the sign's flash safety and endings (`glow`), the clipboard's trips (`sheet`), the studio's mark (`logo`), thumbstick moving (`locomotion`), door plaques (`plaque`) | Anywhere, locally too |
| `npm run test:smoke` | `tests/smoke.mjs`: headless Chromium plays the default room at 20× speed: the sign, taking the clipboard from the board, the corridor/desk light ratio, consent, the room to the last reveal page, and a playtest pass with `?sign=b`; fails on any console error | GitHub Actions only (heavy) |
| `node tools/check-voice.mjs <room>` | Speech-to-text of every recording compared with the script (wrong or skipped words) | Locally, costs ElevenLabs credits |
| `node tools/quest-check.mjs` | Plays the corridor (the clipboard, the two-page form with its seal, the age, door 1) and the room in the headset at 10× speed; fails under 72 fps or on any page error; wakes the headset and puts it to sleep after | Locally, headset on its cable, the preview running |
| `node tools/quest-look.mjs <command>` | In the headset on its USB cable, without the owner: `open` (the test copy) or `open local [port]` (the laptop's server, the preview's port by default, seen by the headset as localhost:3000), `sleep` (ends every check: the laptop charges it slowly), `reload` (past caches), `vr` (enter VR), `frame out.jpg` (what the left eye sees), `eval "<js>"`, `worn on|off` (keep it awake while checking), `levels` (each corridor sound at its game gain and a voice line measured at the output; fails outside the mix: events at most 12 dB under the voice, the hum 15–30 dB under it), `perf` (five seconds of frames: rate, slow frames, draw calls, triangles; fails under 72 fps or at 200 draw calls, Meta's Quest 3 budget) | Locally, headset linked over Wi-Fi |
| `node tools/publish-preview.mjs` | Publishes the game files to the test copy the headset opens (exxxit-game.github.io/object-preview); never the live site | Locally, before a headset check |
| `node tools/quest-wifi.mjs` | Links the headset over Wi-Fi for the tools above, only when the cable is out | Locally |
| `node tools/xr-probe-run.mjs [vr ar mic]` | Presses the capability probe's buttons (`tools/xr-probe.html`) in the headset and prints what WebXR gave | Locally, headset on its cable |
| `node tools/check-cards.mjs`, `node tools/build-catalog.mjs` | Every experiment card's quotes are found in its paper; the catalog is built from the cards (`--check`: up to date) | Locally |
| `node tools/make-voice.mjs`, `node tools/make-sounds.mjs` | Recordings and sounds made from the texts and the sound lists | Locally, costs ElevenLabs credits |
| `node tests/static-server.mjs` | Local preview at http://localhost:3000 (`npm run serve`); the app's preview pane serves it on the port in `.claude/launch.json` (3100), which the headset tools read | Locally |

`?speed=N` (1–100) makes every timing N times faster; such runs are never sent.
Before saying "done", report which of these ran and what they printed.
A new rule in a pure module needs its test first (red), then the change (green).
