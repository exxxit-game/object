# Search coverage

Every area of psychology that could give a room, and whether it has been searched
with the card method (`docs/cards/README.md`). An area is **closed** when a search
agent has looked in it across languages and either carded what fits or written why
nothing fits. Card counts come from `docs/cards/`; status is updated after each search.
